## Common Commands

### IPv4 Commands
```
# Show IP configuration
show ip interface brief

# Show routing table
show ip route

# Ping test
ping 172.16.0.1

# Traceroute
traceroute 192.168.0.1

# Show VLAN configuration
show vlan brief
```

### IPv6 Commands
```
# Show IPv6 configuration
show ipv6 interface brief

# Show IPv6 routing table
show ipv6 route

# Ping test
ping ipv6 2001:db8:1000:4::1

# Traceroute
traceroute ipv6 2001:db8:2000:100::1

# Show IPv6 neighbors
show ipv6 neighbors
```
