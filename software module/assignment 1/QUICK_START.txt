================================================================================
                    QUICK START GUIDE - QUIZ APPLICATION
================================================================================

REQUIREMENTS:
- Python 3.6 or higher

RUN THE QUIZ:
1. Open Command Prompt (Windows) or Terminal (Mac/Linux)
2. Navigate to this folder
3. Run: python quiz_application.py
4. Follow on-screen prompts

FEATURES:
- 11 trivia questions
- Multiple users
- Random question order
- Customizable question count (1-11)
- Detailed feedback and explanations
- Leaderboard and statistics

FILES INCLUDED:
- quiz_application.py     (Main program)
- README.txt              (Detailed documentation)
- test_quiz.py            (Automated tests)
- DEMONSTRATION_GUIDE.txt (Presentation guide)
- QUICK_START.txt         (This file)

TESTING:
Run: python test_quiz.py

For detailed instructions, see README.txt
