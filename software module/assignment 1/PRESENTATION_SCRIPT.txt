"The check_answer function is crucial. It:

--- Quiz Execution (6:00 - 6:45) ---

"The run_quiz function orchestrates the quiz:
- It uses random.sample() to select random questions from the bank
- Initializes score to 0 and an empty results list
- Uses a for loop with a manual counter instead of enumerate
- For each question, it checks the type:
  - If type is 'text', it gets a text answer
  - Otherwise, it displays options and gets a multiple choice answer
- It checks if the answer is correct using our check_answer function
- Updates the score using explicit addition: score = score + 1
- Stores detailed results in a dictionary with explicit key assignments
- Returns both the score and results list"

PART 4: STATISTICS AND MAIN FUNCTION (7:30 - 9:00)
================================================================================

[Scroll to display_statistics function]

--- Statistics Display (7:30 - 8:15) ---

"The display_statistics function demonstrates advanced data processing:
- First, it checks if the results list is empty
- It creates a copy of the results list
- Then implements a bubble sort algorithm to sort by score
- This uses nested for loops with explicit index calculations
- After sorting, it displays a leaderboard using a manual counter
- It finds the highest score and loops through to find all users with that score
- It calculates the average score using a for loop to sum all scores
- Then divides by the number of users
- Finally displays the average score, percentage, and total participants

Notice I'm using manual loops and explicit operations rather than built-in 
functions like sorted() or sum() - this demonstrates understanding of 
fundamental programming concepts."

[Scroll to main function]

--- Main Function (8:15 - 9:00) ---

"The main function ties everything together:
- Displays the welcome screen
- Gets all questions and counts them
- Asks if user wants to customize using get_valid_yes_no
- If yes, gets the number of questions using get_valid_number
- Otherwise defaults to 10 questions
- Initializes an empty results list
- Uses a while loop with a boolean flag 'keep_going'
- For each user:
  - Gets their name
  - Runs the quiz
  - Calculates percentage
  - Stores results in a dictionary with explicit key assignments
  - Displays their results
  - Asks if another user wants to play
- After the loop, checks if more than one user played
- If so, displays statistics
- Finally shows a thank you message

The program also includes error handling at the bottom using try-except 
to catch KeyboardInterrupt and general exceptions."
